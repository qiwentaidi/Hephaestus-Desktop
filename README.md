<h1 align="center">Hephaestus Desktop Client</h1>

这虽然是一个新的项目但是也可作为 Slack v3 版本使用。

相比 v2，v3 的升级重点不只是漏洞数量增加，而是围绕扫描能力、结果管理和实际使用链路做了整体增强：全新扫描策略、全局报告管理、更完善的请求转发，以及从 3400+ 提升到 4900+ 的漏洞覆盖。

## 核心升级

当前版本重点增强了以下几个方向：

- 扫描能力：全新的端口识别与过滤策略，更完善的 JS 漏洞识别与链路分析能力，并持续维护最新 Nuclei 策略
- 结果管理：支持全局报告管理，仪表盘展示更完整，数据沉淀能力更强
- 请求转发：从基础能力升级到覆盖常见使用场景，联动更实用
- 漏洞覆盖：漏洞数量从 3400+ 提升到 4900+
- 使用协同：Web 和桌面端可通过调配数据源实现数据共享与协同使用
